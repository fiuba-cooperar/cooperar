# Identidad visual

Logos de CooperAR.

| Archivo | Qué es |
|---|---|
| `logo-with-tagline.png` | Logo completo: símbolo, nombre y la bajada "Observatorio de cooperativas y empresas recuperadas". |
| `logo.png` | Símbolo y nombre, sin bajada. |
| `symbol.png` | Solo el símbolo (el triángulo con tres puntos). |
| `logo-transparent.png` | Símbolo y nombre, recortados y con fondo transparente. Es el que se usa en el `README.md` principal. |
| `symbol-mocks.png` | Símbolo con los trazos engrosados y fondo transparente, que se usa en los mocks para que se lea bien a tamaños chicos. Es un retoque del `symbol.png`, no el logo oficial. |

Los tres primeros son PNG de 2000×2000 con fondo blanco.
